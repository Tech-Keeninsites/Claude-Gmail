# Claude-Gmail
Daily brief of unread Gmail + Google Calendar, split Internal (@keeninsites.com) / External.

Briefs are written to `briefs/YYYY-MM-DD.md`; a push notification is sent to the Claude app.

## Run manually
Open the routine in Claude Code on the web (claude.ai/code → Routines) and choose **Run now**, or ask Claude: "Run the daily email brief".
